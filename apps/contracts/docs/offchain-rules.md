# Off-chain rules

Generated by `script/PrintOffChainFunctions.s.sol`. Do not edit by hand: the text of each function is in `src/rules/offchain/OffChainFunctions.sol`, and its hash is what a vault commits to.

A rule's **function hash** is `keccak256` of its spec text, exactly as written below. The app must compute this function and nothing else; anyone can recompute a result from the spec and compare it with what the app posted. The result goes to the signal board at the **channel** shown, and the rule's module reads it back and holds it against the vault's limit.

## 1. sector-cap

- **Judges:** the portfolio after every rebalance. **Result is about:** one vault. **Holds when:** result <= the vault's limit.
- **Channel:** `keccak256(abi.encode(functionHash, vault))`.

> sector-cap/1: the largest share of the vault's value held in one sector, in bps. Inputs: the vault's holdings valued at the pools' trusted prices; each stock's sector from Yahoo Finance assetProfile. Cash belongs to no sector. Result: max over sectors of sector value / total value * 10000, rounded down. Holds when result <= limit.
